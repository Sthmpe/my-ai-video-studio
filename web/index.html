The pipeline

Resumable stages, quality gates and automatic retry of bad scenes.

01

Research & script

Wikipedia + rotating free LLM APIs (or Claude Code) write a fact-checked, funny script.

02

Storyboard

Narration timing decides how many shots each scene needs.

03

AI video

AnimateDiff-Lightning on a cartoon checkpoint generates each shot; failures are re-seeded.

04

Voice, music, edit

Kokoro-82M narration, original synthesized score, xfade transitions, burned-in subtitles.
